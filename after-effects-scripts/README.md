# 애프터 이펙트 스크립트 모음

Adobe After Effects에서 쓰는 ExtendScript(`.jsx`) · ScriptUI 스크립트 모음입니다. 따로 설치할 프로그램은 없습니다.

| 파일 | 하는 일 |
|---|---|
| [`scripts/COC_Safe Delete_v0.01.jsx`](scripts/COC_Safe%20Delete_v0.01.jsx) | **COC Safe Delete**: 선택한 레이어(선택이 없으면 컴포지션 전체, Shift를 누르면 안에 든 프리컴프까지)를 지워도 영향이 없는지 검사한 뒤, 안전한 레이어만 삭제. 지우지 않은 레이어는 이유를 알려 주고, Ctrl+클릭하면 이름 끝에 이유 태그를 붙임 |

---

## 1. 파일 받기

- GitHub 저장소 페이지에서 **Code → Download ZIP**으로 받거나, `.jsx` 파일을 열고 **Download raw file** 버튼을 누르세요.
- **코드를 복사해서 메모장 같은 곳에 붙여 넣지 마세요.** 파일 맨 앞의 인코딩 표시(UTF-8 BOM)가 빠지면 한글이 깨집니다.
  이 경우 스크립트가 알아채고 "wrong text encoding" 안내창을 띄운 뒤 멈춥니다.
- 애프터 이펙트는 `.jsx`(또는 `.jsxbin`) 파일만 스크립트로 인식합니다.

## 2. 설치 · 실행

### 방법 A — 도킹 패널로 쓰기 (추천)

1. `.jsx` 파일을 아래 폴더에 복사합니다. (관리자 권한을 물을 수 있습니다)

   | OS | 폴더 |
   |---|---|
   | Windows | `C:\Program Files\Adobe\Adobe After Effects (버전)\Support Files\Scripts\ScriptUI Panels\` |
   | macOS | `응용 프로그램/Adobe After Effects (버전)/Scripts/ScriptUI Panels/` |

2. 애프터 이펙트를 다시 시작합니다.
3. **창(Window)** 메뉴 맨 아래에 있는 `COC_Safe Delete_v0.01.jsx`를 누르면 패널이 열립니다. 원하는 곳에 도킹해 두세요.

### 방법 B — 바로 실행

**파일 > 스크립트 > 스크립트 파일 실행...** 에서 `.jsx` 파일을 고르면 떠 있는 창으로 열립니다.

## 3. COC Safe Delete 사용법

컴포지션 타임라인을 열고 **Safe Delete** 버튼을 누릅니다.

| 누르는 방법 | 검사 대상 | 결과 |
|---|---|---|
| 레이어 **1개** 선택 후 클릭 | 선택한 레이어 | 지워도 되면 조용히 삭제, 안 되면 삭제하지 않고 이유를 알림창에 보여 줌 |
| 레이어 **여러 개** 선택 후 클릭 | 선택한 레이어 | 지워도 되는 것만 삭제하고, **몇 개를 삭제했고 몇 개를 남겼는지**와 남긴 이유를 요약 |
| **아무것도 선택하지 않고** 클릭 | 지금 컴포지션의 **모든 레이어** | 컴포지션 정리. 결과를 요약해서 보여 줌 |
| **아무것도 선택하지 않고 Shift + 클릭** | 지금 컴포지션 + 그 안에 든 **프리컴프를 끝까지** | 컴포지션마다 나눠서 결과를 보여 줌 |

- **Ctrl + 클릭** (macOS는 **Cmd + 클릭**): 위와 같이 정리한 뒤, 남긴 레이어 이름 끝에 이유 태그를 붙입니다. Shift와 함께 누르면(**Ctrl + Shift + 클릭**) 프리컴프 속 레이어에도 붙입니다.
  예) `Null 1 (#Parent)(#Exp_Target)`, `Matte (#Matte)(#Set Matte fx)`
  - 다시 Ctrl+클릭하면 예전 태그를 지우고 지금 상태의 태그로 바꿉니다. 잠긴 레이어는 잠깐 풀어서 이름을 바꾸고 다시 잠급니다.
  - 컴포지션 전체를 정리할 때(선택 없음)는 **화면에 보이거나 소리가 나는 레이어의 이름은 바꾸지 않습니다.** 태그는 숨어 있는데도 남긴 레이어에만 붙습니다. 결과창에서도 이런 레이어는 개수만 보여 줍니다.
  - macOS에서는 Control+클릭이 오른쪽 클릭으로 처리될 수 있으니 Cmd를 쓰세요.
- 레이어를 선택한 상태에서는 Shift를 눌러도 선택한 레이어만 다룹니다.
- 프리컴프 속까지 정리할 때, 한 컴포지션에서 레이어를 지운 덕분에 다른 컴포지션의 레이어를 지울 수 있게 되면(예: 프리컴프 속 숨은 레이어만 쓰던 널) 한 번 더 돌면서 마저 정리합니다.
  같은 프리컴프가 여러 번 들어 있어도 한 번만 정리하고, 지금 컴포지션 밖에 있는 컴포지션은 건드리지 않습니다.
- 모든 작업은 되돌리기(Ctrl+Z) 한 번으로 취소됩니다.

### 지우지 않는 경우와 태그

| 태그 | 이유 | 알림창 예시 |
|---|---|---|
| `(#Locked)` | 잠긴 레이어 | 잠긴(Lock) 레이어입니다. |
| `(#Visible)` | 눈(비디오 스위치)이 켜져 있어 화면에 보이는 레이어 (비디오 · 이미지 · 솔리드 · 셰이프 · 텍스트 · 프리컴프, 가이드 레이어 포함) | 눈(비디오 스위치)이 켜져 있어 화면에 보이는 이미지 레이어입니다. |
| `(#Audio)` | 오디오 스위치가 켜져 있어 소리가 나는 레이어 | 오디오 스위치가 켜져 있어 소리가 나는 레이어입니다. |
| `(#Parent)` | 다른 레이어의 부모 | "Box"(#3) 레이어의 부모입니다. |
| `(#Matte)` | 다른 레이어의 트랙 매트 (2023 이후 방식, 이전 방식 모두) | "Fill"(#4) 레이어의 트랙 매트입니다. (루마 매트) |
| `(#이펙트이름 fx)` | 이펙트의 레이어 선택 항목에 지정됨 (매트 설정, 변위 맵, 레이어 컨트롤, 서드파티 플러그인 등) | "Img"(#5) 레이어의 "Set Matte" 이펙트 타겟으로 설정되어 있습니다. ("Take Matte From Layer") |
| `(#Effect Target)` | 이펙트가 아닌 곳의 레이어 선택 항목에 지정됨 | "A"(#2) 레이어의 "…" 항목에 레이어로 지정되어 있습니다. |
| `(#Light Source)` | 환경 라이트의 소스 레이어 (AE 2024 이상) | "Env"(#1) 라이트의 소스 레이어로 쓰이고 있습니다. |
| `(#Exp_Target)` | 익스프레션이 이름(`layer("이름")`)이나 번호로 이 레이어를 가리킴 — 다른 컴포지션의 `comp("이름").layer(...)`, 프리컴프 안을 가리키는 `.source.layer(...)`까지 확인 | "Text"(#2) 레이어의 "Transform > Position" 프로퍼티 익스프레션의 타겟으로 사용되고 있습니다. |
| `(#Exp_Index)` | 지우면 레이어 번호가 밀려서 익스프레션 결과가 바뀜 (`layer(5)` 같은 번호 참조, `layer(index-1)` 같은 상대 참조, `index` 사용) | … 익스프레션이 자기 레이어 번호(index)를 쓰고 있어, 지우면 번호가 바뀌어 결과가 달라집니다. |
| `(#Exp_NumLayers)` | 익스프레션이 레이어 개수(`numLayers`)를 씀 | … 레이어 개수(numLayers)를 쓰고 있어, 지우면 결과가 달라집니다. |
| `(#Exp_Dynamic)` | 익스프레션이 계산한 값으로 레이어를 찾음 (`layer(i)` 등) | … 계산한 값으로 레이어를 찾고 있어, 지우면 결과가 달라질 수 있습니다. |
| `(#EGP)` | 에센셜 그래픽스 패널에 마스터 프로퍼티 · 미디어 교체로 등록됨 (AE 2022 이상) | 이 레이어의 "Transform > Position" 프로퍼티가 에센셜 그래픽스 패널에 "Logo Position" (마스터 프로퍼티)로 등록되어 있습니다. |
| `(#Adjustment)` | 이펙트가 켜진 조정 레이어이고, 같은 시간대에 아래에 보이는 레이어가 있음 | 이펙트가 켜진 조정 레이어로, 아래 레이어 3개(…)의 모습을 바꾸고 있습니다. |
| `(#Light)` | 켜진 라이트이고, 빛을 받는 3D 레이어가 있음. 3D 레이어가 없어도 컴포지션 라이트를 읽을 수 있는 이펙트(Particular · Element 3D 같은 서드파티, 카드 댄스 · 셰터 등)가 있으면 남김 | 라이트로서 3D 레이어 2개(…)를 비추고 있습니다. |
| `(#Camera)` | 3D 레이어가 보이는 시점을 정하는 카메라 (위쪽 카메라에 완전히 가려진 카메라는 제외). 라이트와 같이 카메라를 읽을 수 있는 이펙트가 있으면 남김 | 컴포지션 카메라로서 3D 레이어 4개(…)의 시점을 정하고 있습니다. |
| `(#Solo)` | 하나뿐인 솔로 레이어 (지우면 솔로가 풀려 숨어 있던 레이어가 다시 보임) | 솔로(Solo)가 켜진 레이어입니다. … |

- 꺼져 있는 익스프레션도 다시 켤 수 있으므로 똑같이 검사하고, 알림창에 "(지금은 꺼져 있는 익스프레션)"이라고 적습니다.
- 주석(`//`, `/* */`)이나 문자열 안의 글자, `nearestKey(time).index` 같은 키 번호는 레이어 참조로 보지 않습니다.
- 여러 개를 함께 지울 때는, **같이 지워지는 레이어끼리의 연결은 문제로 보지 않습니다.** 예를 들어 숨긴 널과 그 자식(숨김)을 함께 고르면 둘 다 지웁니다.
  반대로 남겨야 하는 레이어가 생기면, 그 레이어가 기대는 레이어도 함께 남깁니다.

### 지워도 되는 레이어의 예

- 눈이 꺼져 있고 아무 데서도 쓰지 않는 솔리드 · 셰이프 · 푸티지 (소리도 꺼져 있을 때)
- 아무도 부모로 쓰지 않고 익스프레션에서도 가리키지 않는 널
- 이펙트가 없거나 아래에 보이는 레이어가 없는 조정 레이어
- 3D 레이어도, 카메라를 읽는 이펙트도 없는 컴포지션의 카메라 · 라이트, 꺼져 있는 카메라 · 라이트

### 알아 둘 점

- 누를 때마다 **프로젝트 전체의 익스프레션**을 한 번 훑기 때문에, 아주 큰 프로젝트에서는 몇 초 걸릴 수 있습니다.
- `var c = comp("Main"); c.layer("Null")`처럼 변수에 담은 경우는, 같은 컴포지션이거나 식 안에 이 컴포지션 이름이 적혀 있을 때 참조로 봅니다.
- 2D 레이어에서 컴포지션 카메라 · 라이트를 읽는 이펙트는 이름으로 추측합니다. 어도비 기본 이펙트(`ADBE …`, `CC …`) 중 카드 댄스 · 카드 와이프 · 셰터 · 커스틱이 아닌 것은 카메라를 읽지 않는다고 보고, 그 밖의 이펙트는 모두 읽을 수 있다고 봅니다. 그래서 서드파티 이펙트가 있는 컴포지션에서는 쓰지 않는 카메라 · 라이트도 남을 수 있습니다.
- 모션 트래커의 대상(Motion Target)처럼 스크립트로 읽을 수 없는 연결은 검사하지 못합니다.
- 태그를 붙이면 레이어 이름이 바뀝니다. 애프터 이펙트가 이름으로 가리키던 익스프레션을 새 이름으로 고쳐 주는데,
  고쳐지지 않은 것이 확인되면 그 레이어는 이름을 되돌리고 알림창에 적어 둡니다.
- 에센셜 그래픽스 검사는 이 컴포지션을 쓰는 레이어가 없으면 잠깐 임시 컴포지션을 만들어 읽고 바로 지웁니다.

## 4. 개발 · 테스트

`dev/` 폴더에는 애프터 이펙트 없이 스크립트를 검사하는 도구가 있습니다. (Node.js 18 이상)

```bash
cd after-effects-scripts/dev
npm install
npm test
```

- `lint.js` — UTF-8 BOM, ES3 문법(ExtendScript), ES5 이후 기능 사용, 인코딩 안내문 확인
- `encoding.js` — BOM 없이 다른 코드 페이지로 읽혀도 안내창이 제대로 뜨는지 확인
- `harness.js` — ES3 실행 환경 + ScriptUI · After Effects DOM 흉내 (컴포지션 · 레이어 · 프로퍼티 · 익스프레션 · 트랙 매트 · 에센셜 프로퍼티)
- `tests.js` — 부모 · 매트 · 이펙트 · 익스프레션 · 조정 레이어 · 카메라 · 라이트 · 솔로 · 에센셜 그래픽스 · 여러 개 삭제 · 컴포지션 전체 · 프리컴프 속까지 · 태그 붙이기 시나리오
