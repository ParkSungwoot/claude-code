# 일러스트레이터 UI 스크립트 모음

Adobe Illustrator에서 **창(대화상자)을 띄워 옵션을 고른 뒤 실행하는** 스크립트 모음입니다.
일러스트레이터에 기본으로 들어 있는 ExtendScript(`.jsx`)와 ScriptUI로 만들었기 때문에 따로 설치할 프로그램이 없습니다.

| 파일 | 하는 일 |
|---|---|
| [`scripts/COC_illust Essential.jsx`](scripts/COC_illust%20Essential.jsx) | **COC_illust Essential**: 정렬 패널처럼 띄워 두고 쓰는 패널. 간격 같게 배열 · 간격 스포이드 · 격자로 정리 · 크기 맞추기 · 아트보드에 맞추기, 회전 맞추기 · 포인트 기준 회전, 제자리 단락 정렬 · 기준선 정렬 · 어간 조절, 아트보드 리어레인지 · 리네이밍 · 아트워크 트림, 빈 레이어 삭제 · 불투명도 정리(애프터 이펙트용) |
| [`scripts/BatchRename.jsx`](scripts/BatchRename.jsx) | **일괄 이름 변경 · 번호 매기기** — 대지 · 레이어 · 객체 이름, 텍스트 내용을 규칙대로 한꺼번에 바꾸기 |
| [`scripts/GridArrange.jsx`](scripts/GridArrange.jsx) | **격자 정렬** — 선택한 객체를 열 수 · 간격 · 정렬 기준에 맞춰 바둑판처럼 배치 (미리보기 지원) |
| [`scripts/ExportArtboards.jsx`](scripts/ExportArtboards.jsx) | **대지 내보내기** — 대지를 PNG · JPG · SVG · PDF 파일로 한 번에 저장 (해상도 · 파일 이름 규칙 지정) |
| [`template/UITemplate.jsx`](template/UITemplate.jsx) | **새 스크립트용 뼈대** — 창 만들기, 입력값 검사, 미리보기, 설정 기억이 들어 있는 예제 |

COC_illust Essential은 한 번 띄워 두면 계속 열려 있는 패널이고, 나머지는 창에서 결과를 미리 확인한 뒤 적용하는 방식입니다. 마지막에 입력한 값은 다음 실행 때 그대로 불러옵니다.

---

## 1. 파일 받기

- GitHub 저장소 페이지에서 **Code → Download ZIP**으로 받거나, 각 `.jsx` 파일을 열고 **Download raw file** 버튼을 누르세요.
- **코드를 복사해서 메모장 같은 곳에 붙여 넣지 마세요.** 파일 맨 앞의 인코딩 표시(UTF-8 BOM)가 빠지면 일러스트레이터에서 한글이 깨집니다.
  이 경우 스크립트가 알아채고 "wrong text encoding" 안내창을 띄운 뒤 멈춥니다. 해결 방법은 [문제 해결](#6-문제-해결)을 보세요.

## 2. 실행하기

### 방법 A — 바로 실행 (설치 없이)

1. 일러스트레이터에서 문서를 엽니다.
2. **파일 > 스크립트 > 기타 스크립트...** (Windows `Ctrl+F12`, macOS `⌘+F12`)
3. 실행할 `.jsx` 파일을 선택합니다.

### 방법 B — 스크립트 메뉴에 등록

`.jsx` 파일을 아래 폴더에 복사한 뒤 일러스트레이터를 다시 시작하면 **파일 > 스크립트** 메뉴에 바로 나타납니다.

| OS | 폴더 |
|---|---|
| Windows | `C:\Program Files\Adobe\Adobe Illustrator (버전)\Presets\ko_KR\` 안의 `스크립트` 폴더 |
| macOS | `응용 프로그램/Adobe Illustrator (버전)/Presets/ko_KR/` 안의 `스크립트` 폴더 |

- 영문판은 `en_US` 안의 `Scripts` 폴더입니다. 언어에 따라 폴더 이름이 다를 수 있습니다.
- 복사할 때 관리자 권한을 요구할 수 있습니다.
- 메뉴에는 파일 이름이 그대로 보이므로, 원하면 `일괄이름변경.jsx`처럼 파일 이름을 바꿔도 됩니다.

### 단축키 지정하기 (선택)

방법 B로 등록한 스크립트는 액션으로 단축키를 붙일 수 있습니다.

1. **창 > 액션** 패널에서 새 세트와 새 액션을 만듭니다. 이때 기능 키(F2~F12)를 지정합니다.
2. 녹화를 멈춘 뒤, 액션 패널 메뉴(≡)에서 **메뉴 항목 삽입...** 을 선택합니다.
3. 창이 떠 있는 상태에서 **파일 > 스크립트 > (스크립트 이름)** 을 클릭하고 확인합니다.

일부 버전에서는 일러스트레이터를 다시 켜면 액션 속 스크립트 항목이 사라지기도 합니다. 그럴 때는 3번을 다시 해 주세요.

---

## 3. 스크립트별 사용법

### 3-0. COC_illust Essential (`COC_illust Essential.jsx`)

실행하면 **정렬 패널처럼 계속 떠 있는 패널**이 열립니다. 창을 띄워 둔 채로 객체를 선택하고 버튼만 누르면 됩니다.
스크립트를 다시 실행하면 새 창을 만들지 않고 열려 있는 패널을 앞으로 가져옵니다. 기능은 **간격 · 크기**, **회전**, **텍스트**, **정리** 탭에 나뉘어 있고, 결과는 패널 맨 아래에 표시됩니다. 모든 작업은 실행 취소(Ctrl/⌘+Z)로 되돌릴 수 있습니다.

**[간격 · 크기] 탭**

| 버튼 · 옵션 | 설명 |
|---|---|
| **가로 간격 같게** / **세로 간격 같게** | 왼쪽 → 오른쪽(위 → 아래) 순서로, 객체 사이의 빈 간격을 모두 같게 만듭니다. 크기가 서로 달라도 됩니다. |
| 자동 (양 끝 고정) | 맨 앞과 맨 끝 객체는 그대로 두고 사이 간격만 똑같이 나눕니다. (3개 이상) |
| 직접 입력 | 간격을 `5 mm`처럼 정확히 지정합니다. (2개 이상) 단위는 mm · cm · pt · px · in 중에서 고릅니다. |
| 기준 | 직접 입력할 때 어느 쪽을 제자리에 둘지 고릅니다: 처음 객체 고정 / 가운데 고정 / 끝 객체 고정 |
| **스포이드** | 두 객체를 선택하고 누르면 그 사이 간격을 읽어 간격 칸에 넣고 '직접 입력'으로 바꿔 둡니다. 이어서 다른 객체들을 선택하고 간격 같게 버튼을 누르면 같은 간격이 적용됩니다. 나란히 있으면 가로 간격, 위아래로 있으면 세로 간격을 읽습니다. |
| **격자로 정리** | 대충 흩어 놓은 객체의 행과 열을 알아서 찾아 같은 간격의 격자로 정리합니다. (Figma의 Tidy up) 자동이면 지금 간격들의 평균, 직접 입력이면 그 간격을 씁니다. 각 객체는 칸 가운데에 놓이고, 전체의 왼쪽 위 모서리는 그대로입니다. |
| **크기 맞추기** | 맞출 크기(폭 / 높이 / 폭과 높이)를 기준 객체(가장 큰 객체 / 가장 작은 객체 / 맨 위 객체 / 키 오브젝트)에 맞춥니다. 각 객체는 제 가운데를 중심으로 커지거나 작아집니다. |
| 비율 유지 | 켜면 가로세로 비율을 지킵니다. '폭과 높이'에서는 기준 크기 안에 들어가도록 맞춥니다. |
| **아트보드 너비에 맞게** / **아트보드 높이에 맞게** | 선택한 객체를 놓인 아트보드의 너비(높이)에 딱 맞추고 양옆(위아래)을 아트보드 가장자리에 붙입니다. 다른 방향은 가운데 위치를 지킵니다. 비율 유지를 따릅니다. |

> 참고: 정렬 패널에도 '분포 간격(Distribute Spacing)'이 있지만, 패널 메뉴에서 **옵션 표시**를 켜야 보이고 간격 값을 정하려면 키 오브젝트를 한 번 더 클릭해야 합니다. 이 패널은 버튼 한 번으로, mm 같은 원하는 단위로 바로 지정합니다.

- '폭과 높이'에서 가장 큰(작은) 객체는 면적으로 고릅니다.
- **키 오브젝트**: 여러 객체를 선택한 뒤 기준으로 쓸 객체를 한 번 더 클릭하면 굵은 테두리로 표시되는 객체입니다.
  스크립트는 키 오브젝트를 직접 읽을 수 없어서, 정렬 명령(위 · 오른쪽 · 아래 · 왼쪽 맞춤)을 잠깐 실행해 움직이지 않는 객체를 찾은 뒤 모두 제자리로 돌려놓습니다.
  키 오브젝트가 없으면 '키 오브젝트를 찾지 못했습니다'라고 알려 주고 아무것도 바꾸지 않습니다. (다른 객체를 모두 감싸는 객체가 있으면 그 객체를 키 오브젝트로 볼 수 있습니다)
- 선 두께가 함께 커지는지는 환경 설정의 **선과 효과 크기 조정**을 따릅니다. 선 두께 때문에 크기가 조금 어긋나면 다시 재서 맞춥니다.
- 아트보드에 맞출 때는 객체와 가장 많이 겹치는 아트보드를 씁니다. 어느 아트보드에도 닿지 않으면 지금 선택된(활성) 아트보드를 씁니다.

**[회전] 탭**

| 버튼 · 옵션 | 설명 |
|---|---|
| **0°로 초기화** | 돌려 놓은 객체를 똑바로 되돌립니다. 제 가운데를 중심으로 돕니다. |
| **맨 위 객체 각도로** | 레이어 순서상 맨 위 객체의 각도에 나머지를 맞춥니다. |
| 각도 + **각도 적용** | 입력한 각도(반시계 방향이 +)로 맞춥니다. 지금 몇 도인지와 상관없이 그 각도가 됩니다. |
| **포인트 기준 수직 회전** / **포인트 기준 수평 회전** | 직접 선택 도구(A)로 점 두 개를 고르고 누르면, 두 점이 위아래로(수직) 또는 옆으로(수평) 나란해지도록 점이 속한 객체를 돌립니다. |
| **포인트 기준 각도 스포이드** | 점 두 개를 고르고 누르면 두 점을 잇는 선의 각도(-90° ~ 90°, 반시계 방향 +)를 **읽은 각도** 칸에 넣습니다. 다른 객체를 선택하고 옆의 **적용**을 누르면 그 객체가 이 각도로 맞춰집니다. |

- 포인트 기준 회전은 점이 속한 객체 전체를 돌립니다. 그룹 안의 점이면 그룹 전체, 두 점이 서로 다른 객체에 있으면 두 객체를 한 덩어리처럼 함께 돌립니다.
  두 점의 가운데를 중심으로, 가장 적게 도는 방향(90° 이하)으로 돌기 때문에 객체가 뒤집히지 않습니다. 점은 정확히 두 개여야 합니다.
- 각도 스포이드의 **적용**은 '각도 적용'처럼 객체를 그 각도로 **맞춥니다**. (이미 40° 돌아간 객체도 그 각도가 됨) 칸에는 소수 셋째 자리까지 보이지만, 칸을 고치지 않았으면 읽은 정확한 값으로 적용합니다.
- 회전 각도는 텍스트와 이미지는 객체 자체에서 읽고, 그 밖의 객체는 일러스트레이터가 기억해 둔 회전 값(변형 패널에 보이는 각도)에서 읽습니다.
  이 값은 일러스트레이터에서 직접 돌렸을 때만 남기 때문에, 다른 스크립트로 돌렸거나 다른 프로그램에서 가져온 객체에는 없을 수 있습니다.
  이런 객체는 0°로 초기화할 때 **'회전 정보가 없는 N개는 그대로 두었습니다'**라고 알려 주고, 각도 적용과 맨 위 객체 각도로에서는 0°로 보고 돌립니다.
- 이 패널로 돌린 객체는 변형 패널에 보이는 각도도 함께 맞춰 둡니다. 포인트 기준 회전은 원래 회전 값이 있던 객체만 그만큼 더해 두고, 없던 객체는 똑바로 선 테두리 상자를 그대로 둡니다.

**[텍스트] 탭**

| 버튼 · 옵션 | 설명 |
|---|---|
| **왼쪽 / 가운데 / 오른쪽** | 단락 정렬을 바꾸되 포인트 텍스트가 움직이지 않도록 되돌려 놓습니다. 텍스트 상자의 왼쪽(가운데 · 오른쪽)이 원래 자리에 남습니다. |
| **양쪽 정렬 / 강제 양쪽** | 영역 텍스트용입니다. 포인트 텍스트는 건너뜁니다. |
| **기준선 맞추기** | 크기가 다른 글자들의 첫 줄 기준선(글자가 올라앉는 선)을 한 높이로 맞춥니다. 기준선 위치는 가장 왼쪽 텍스트 / 가장 위 기준선 / 가장 아래 기준선 / 평균 중에서 고릅니다. |
| 텍스트가 아닌 객체는 아랫변을 맞춤 | 아이콘처럼 함께 선택한 객체의 아랫변을 그 기준선에 맞춥니다. |
| **어간** (띄어쓰기 간격) | 띄어쓰기 글자에만 자간을 주어 단어 사이만 넓히거나(+) 좁힙니다(−). 단위는 자간과 같은 1/1000 em입니다. **적용**은 입력한 값으로, **-10 / +10**은 지금 값에서 조금씩, **0으로**는 원래대로 되돌립니다. |

- 단락 정렬과 어간은 그룹 안의 텍스트에도 적용됩니다. 글자를 편집 중이면 선택한 부분만 바꾸고, 커서만 두었으면 텍스트 전체를 바꿉니다.
- 영역 텍스트는 틀이 움직이지 않으므로 틀 안에서 정렬만 바뀝니다. 세로쓰기 텍스트와 회전된 텍스트도 제자리를 유지합니다. (회전된 여러 줄 텍스트는 거의 제자리)
- 패스 위의 텍스트는 정렬을 바꾸면 글자가 패스를 따라 움직이므로 위치를 유지할 수 없습니다.
- 기준선 맞추기는 가로쓰기 포인트 텍스트만 맞추고, 영역 · 패스 · 세로쓰기 텍스트는 건너뜁니다.
- 어간은 일반 띄어쓰기, 줄바꿈 없는 공백, 전각 공백만 바꿉니다. 글자 사이의 자간은 그대로입니다.

**[정리] 탭**

| 버튼 · 옵션 | 설명 |
|---|---|
| **아트보드 리어레인지** | 기본 기능(모든 대지 재배열)과 달리 **지금 놓인 순서**를 따릅니다. 왼쪽 위에 있을수록 앞 번호, 오른쪽 아래에 있을수록 뒤 번호가 되도록 아트보드 번호를 다시 매기고, 그 순서대로 격자로 정리합니다. 아트보드 위의 객체도 함께 옮깁니다. |
| 지금 행 유지 / 열 수 | 지금 한 줄에 놓인 아트보드들을 그대로 한 줄로 둘지, 한 줄에 몇 개씩 놓을지 고릅니다. |
| 간격 | 아트보드 사이 간격. 단위는 [간격 · 크기] 탭의 단위를 따릅니다. |
| **아트보드 리네이밍** | 아트보드 패널 순서대로 이름을 1, 2, 3 … 으로 바꿉니다. **01, 02 …** 을 켜면 자릿수를 맞춥니다. |
| **아트워크 트림** | 아트보드 밖으로 나간 객체만 아트보드 크기의 클리핑 마스크로 잘라 냅니다. 아트보드 안에 다 들어 있는 객체는 그대로 둡니다. |
| **트림 해제** | 아트워크 트림으로 만든 클리핑 마스크만 풀어서, 객체를 원래 자리(레이어와 쌓인 순서)로 돌려놓습니다. 직접 만든 클리핑 마스크는 건드리지 않습니다. |
| **빈 레이어 삭제** | 아무것도 들어 있지 않은 레이어와 하위 레이어를 지웁니다. 잠긴 빈 레이어도 지우고, 레이어가 하나도 안 남게 되면 맨 위 하나는 남깁니다. |
| **오퍼시티 표시** | 불투명도가 100%가 아닌 객체를 제 레이어로 빼고 레이어 이름 뒤에 `_(opacity 60%)`처럼 적은 뒤, 불투명도를 100%로 바꿉니다. 애프터 이펙트에서 그 레이어의 불투명도(T)를 이름에 적힌 값으로 다시 주면 됩니다. |
| **오퍼시티 대신 컬러로** | 밑에 깔린 베이스 객체와 그 위의 반투명 객체를 함께 선택하고 누르면, 반투명 객체를 불투명도 100%로 바꾸면서 원래와 똑같이 보이는 색으로 바꿉니다. |

- 리어레인지할 때 잠긴 객체와 잠긴 · 숨긴 레이어는 잠깐 풀어서 함께 옮기고, 끝나면 원래대로 다시 잠그고 숨깁니다.
- 여러 아트보드에 걸친 객체는 가장 많이 겹치는 아트보드를 따라가고, 어느 아트보드에도 닿지 않는 객체는 그 자리에 둡니다.
- 아트보드가 캔버스 밖으로 나가게 되면 아무것도 바꾸지 않고 알려 줍니다. 간격을 줄이거나 열 수를 바꿔 다시 해 보세요.
- 리어레인지 후에는 번호가 놓인 순서와 같아지므로, 이어서 리네이밍하면 이름도 그 순서대로 붙습니다.
- 트림은 객체마다 따로 클리핑 그룹을 만들어서, 객체가 있던 레이어와 쌓인 순서가 그대로입니다. 두 아트보드에 걸친 객체는 두 아트보드를 합친 모양으로 잘립니다.
- 트림은 잠기거나 숨긴 객체, 안내선은 건드리지 않습니다. 한 번 더 눌러도 이미 잘린 객체는 다시 자르지 않습니다.
- **오퍼시티 표시**는 반투명 객체의 위아래에 있던 객체들도 각자 레이어로 나눠서, 쌓인 순서(보이는 모습)가 그대로입니다.
  예) `배경` 레이어에 [a, 반투명 X, b] → `배경`[a], `배경_(opacity 60%)`[X], `배경`[b].
  레이어에 반투명 객체만 하나 있으면 새 레이어를 만들지 않고 이름만 바꿉니다. 잠기거나 숨긴 레이어 · 객체도 처리하고 원래 상태로 되돌립니다.
  그룹 안에 들어 있는 반투명 객체는 그룹을 깨야 해서 그대로 두고, 몇 개인지 알려 줍니다.
- **오퍼시티 대신 컬러로**는 선택한 것 중 맨 아래 객체를 베이스로, 그 위의 반투명 객체들을 모두 바꿉니다. 베이스의 칠 색을 기준으로 계산하므로, 반투명 객체가 베이스 밖으로 나간 부분은 원래와 다르게 보일 수 있습니다.
  RGB · CMYK · 회색 단색, 합성 모드는 표준(보통) · 곱하기 · 스크린을 지원합니다. 그룹 · 복합 패스 · 텍스트 안의 색도 바꿉니다.
  그라디언트 · 패턴 · 별색 · 이미지, 다른 합성 모드인 객체는 건드리지 않고 알려 줍니다.

**측정 기준** (패널 아래, 모든 탭 공통)

| 옵션 | 설명 |
|---|---|
| 선 두께 포함 | 선 두께까지 포함한 크기로 간격 · 격자 · 크기를 계산합니다. |
| 글자 모양 기준 | 텍스트를 텍스트 상자 대신 **실제 글자 외곽**으로 잽니다. 글자 위아래 여백 때문에 간격이 고르지 않아 보일 때 켜세요. 윤곽선으로 바꾼 임시 복사본을 재고 바로 지우므로 원본 텍스트는 그대로입니다. (텍스트가 많으면 조금 느려질 수 있습니다) |
| 클리핑 마스크 | 옵션 없이 항상 마스크 모양(보이는 부분) 기준으로 잽니다. |

### 3-1. 일괄 이름 변경 · 번호 매기기 (`BatchRename.jsx`)

| 항목 | 설명 |
|---|---|
| 대상 | **대지** / **레이어** (하위 레이어 포함 가능) / **선택 객체** (이름) / **선택 텍스트** (글자 내용 자체를 바꿈) |
| 순서 | 기본 순서, **가로 방향**(위 행부터 왼쪽 → 오른쪽), **세로 방향**(왼쪽 열부터 위 → 아래), 역순 |
| 새 이름 짓기 | 패턴과 기호로 새 이름을 만듭니다. 시작 번호와 증가 값(음수 가능)을 정할 수 있습니다. |
| 찾아서 바꾸기 | 이름 일부만 바꿉니다. 대소문자 구분, 정규식(`$1`, `$2` 사용 가능)을 지원합니다. |
| 미리보기 | 창 아래 목록에 `원래 이름 → 새 이름`이 바로 보이고, 몇 개가 바뀌는지 알려 줍니다. |

**패턴 기호**

| 기호 | 결과 | 예 (`시작 번호` 1) |
|---|---|---|
| `{n}` | 번호 | `Page {n}` → Page 1, Page 2 … |
| `{nn}`, `{nnn}` … | 자릿수를 맞춘 번호 | `Page_{nn}` → Page_01, Page_02 … |
| `{name}` | 원래 이름 (텍스트면 원래 내용) | `{name}_final` → 로고_final … |

**활용 예**

- **번호표 · 티켓 넘버링**: 번호 텍스트 여러 개 선택 → 대상 `선택 텍스트` → 패턴 `{nnn}` → 정렬 `가로 방향` → 001, 002, 003 …
- **대지 이름 정리**: 대상 `대지` → 패턴 `표지_{nn}` 또는 찾아서 바꾸기로 `Artboard` → `Page`
- **이름 뒤에 버전 붙이기**: 패턴 `{name}_v2`

### 3-2. 격자 정렬 (`GridArrange.jsx`)

객체를 2개 이상 선택하고 실행합니다.

| 항목 | 설명 |
|---|---|
| 열 수 | 한 줄에 놓을 객체 수. 처음에는 개수에 맞춰 자동으로 들어갑니다(예: 9개 → 3). |
| 채우는 방향 | 가로 방향(한 행씩) / 세로 방향(한 열씩) |
| 간격 | 가로 · 세로 간격과 단위(mm, cm, pt, px, in). 단위를 바꾸면 입력한 값도 환산됩니다. |
| 칸 크기 | 가장 큰 객체 기준(모든 칸 같은 크기) / 행 · 열마다 맞춤(촘촘하게) |
| 칸 안 정렬 | 가로: 왼쪽 · 가운데 · 오른쪽, 세로: 위 · 가운데 · 아래 |
| 순서 | 현재 위치(가로 방향 / 세로 방향), 선택 목록 순서, 이름 순서(Item2 < Item10), 역순 |
| 선 두께 포함 | 켜면 선 두께까지 포함한 크기로 계산합니다. 처음 값은 일러스트레이터의 '미리보기 경계 사용' 설정을 따릅니다. |
| 미리보기 | 값을 바꿀 때마다 문서에 바로 반영됩니다. **취소**하면 원래 자리로 돌아갑니다. |

- 선택한 객체들이 차지하던 영역의 **왼쪽 위 모서리**부터 배치합니다.
- 클리핑 마스크는 가려진 부분을 빼고 **보이는 모양** 기준으로 배치합니다.
- 적용한 뒤 **실행 취소(Ctrl/⌘+Z) 한 번**으로 원래 배치로 돌아갑니다.

### 3-3. 대지 내보내기 (`ExportArtboards.jsx`)

| 항목 | 설명 |
|---|---|
| 대상 | 현재 문서 / 열린 문서 모두 · 모든 대지 / 현재 대지만 / 범위(`1-3, 5`, `2~4`) |
| PNG | 해상도(ppi), 투명 배경 |
| JPG | 해상도(ppi), 품질(0~100) |
| SVG | 텍스트를 윤곽선으로 변환 (글꼴이 없는 곳에서도 똑같이 보임), 이미지는 파일 안에 포함 |
| PDF | 일러스트레이터에 있는 PDF 사전 설정 중 선택 (CC 2018 이상) |
| 파일 이름 | `{doc}` 문서 이름, `{artboard}` 대지 이름, `{n}` 대지 번호(`{nn}` → 01). 예: `{doc}_{artboard}` → `poster_표지.png` |
| 저장 위치 | 문서와 같은 폴더 / 직접 고른 폴더. 저장한 적 없는 새 문서는 고른 폴더에 저장됩니다. |
| 덮어쓰기 | 끄면 같은 이름이 있을 때 `이름_2`, `이름_3` … 으로 저장합니다. |

- 해상도 72ppi가 원래 크기(100%)입니다. 일러스트레이터의 내보내기 배율 한계(776%) 때문에 PNG · JPG는 최대 558ppi까지 입력할 수 있습니다.
- 파일 이름에 쓸 수 없는 글자(`\ / : * ? " < > |`)는 `_`로 바뀝니다.
- 내보내는 동안 진행 상황 창이 뜨고, 끝나면 결과와 저장 위치를 알려 줍니다. '끝나면 폴더 열기'를 켜 두면 폴더도 열어 줍니다.
- 문서는 수정하지 않습니다. 원래 선택돼 있던 대지와 문서로 되돌려 놓습니다.

## 5. 나만의 UI 스크립트 만들기

[`template/UITemplate.jsx`](template/UITemplate.jsx)를 복사해서 시작하면 됩니다. 예제로 '선택한 객체를 입력한 거리만큼 이동'하는 기능과 미리보기가 들어 있고, 파일 맨 위 주석에 고칠 곳 4군데가 적혀 있습니다.

```javascript
var win = new Window('dialog', '창 제목');          // 창 만들기
var row = win.add('group');                         // 한 줄
row.add('statictext', undefined, '가로:');           // 글자
var input = row.add('edittext', undefined, '10');   // 입력 칸
input.characters = 8;
var ok = win.add('button', undefined, '확인', { name: 'ok' });
input.onChanging = function () { /* 입력할 때마다 실행 */ };
if (win.show() === 1) { /* 확인을 눌렀을 때 할 일 */ }
```

자주 쓰는 컨트롤: `statictext`(글자), `edittext`(입력 칸), `button`, `checkbox`, `radiobutton`, `dropdownlist`, `slider`, `listbox`, `progressbar`, `panel`(제목 있는 상자), `group`(줄 맞춤용 묶음)

직접 수정할 때는 편집기에서 **UTF-8 (BOM)** 인코딩으로 저장하세요. (이 폴더의 `.editorconfig`가 지원 편집기에서 자동으로 맞춰 줍니다.)

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| "wrong text encoding" 안내창이 뜨거나 한글이 깨짐 | 파일을 **UTF-8 (BOM)** 으로 저장하세요. VS Code: 오른쪽 아래 `UTF-8` 클릭 → *Save with Encoding* → *UTF-8 with BOM*. 메모장: *다른 이름으로 저장* → 인코딩 *BOM이 있는 UTF-8*. |
| 스크립트 메뉴에 안 보임 | 폴더 위치를 확인하고 일러스트레이터를 완전히 껐다가 다시 켜세요. 급하면 *기타 스크립트...* 로 실행하면 됩니다. |
| "텍스트를 편집하는 중" 안내 | 글자 안에 커서가 있는 상태입니다. `Esc`로 편집을 끝낸 뒤 다시 실행하세요. |
| 대지 내보내기에 PDF 항목이 없음 | PDF는 Illustrator CC 2018 이상에서만 지원합니다. |
| COC_illust Essential 버튼을 눌러도 반응이 없음 | 패널을 닫고 스크립트를 다시 실행해 보세요. 그래도 안 되면 일러스트레이터를 다시 시작하세요. |
| 오류 창이 뜸 | 창에 나온 메시지와 줄 번호를 알려 주시면 고칠 수 있습니다. |

## 7. 지원 환경

- Adobe Illustrator CC 2018 이상 권장 (Windows · macOS). SVG는 CC 2017 이상, PDF는 CC 2018 이상이 필요합니다.
- 중요한 작업에 처음 쓸 때는 **복사본 문서에서 한 번 확인**해 보시길 권장합니다.

## 개발자용: 모의 테스트 (`dev/`)

일러스트레이터 없이 스크립트를 검사하는 도구입니다. 스크립트만 쓰실 분은 무시해도 됩니다.

cd dev
npm install
